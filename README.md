\# 🎓 Student Grade Manager



A command-line Student Grade Manager built in Python using OOP and JSON persistence.



\## ✨ Features

\- Add / remove students

\- Add grades per subject

\- Calculate averages and letter grades (A–F)

\- Class-wide statistics and top student

\- Data saved automatically to `grades.json`



\## 🚀 How to Run

```bash

python main.py
